## 6. デザイン仕様

**色**（`style.css` の `:root`）

| トークン | 値 | 用途 |
|---|---|---|
| `--forest` | `#1F3A29` | 見出し、相談欄の背景 |
| `--green-dark` | `#2C6B2F` | ボタン、ラベル、リンク |
| `--green` | `#3E8E41` | アクセント、番号 |
| `--green-pale` | `#EAF5E6` | 支援内容の背景、アイコン地 |
| `--warm` | `#FFFDF6` | ヒーロー・進め方・運営の背景（生成り） |
| `--orange` | `#E87A2E` | 小さな差し色、フォーカス枠 |
| `--ink` / `--muted` / `--faint` | `#252B23` / `#5A6356` / `#7D8679` | 本文／補足／注記 |

- 背景は白・生成り・淡緑・濃緑の4色だけを使う。
- **書体**：見出し（H1・H2・価格・番号）は明朝、本文はゴシック。いずれも端末の書体（Mac＝ヒラギノ／Windows＝游／その他＝Noto）で、外部フォントは使わない。見出しは `palt` で字詰め。
- **文字サイズ**：H1 40〜64px、H2 28〜40px（スマホ24〜28px）、本文15〜16px、補足11〜13px。
- **改行**：見出しは語句単位で `.nw`（改行させないまとまり）を使い、`word-break:auto-phrase` と `text-wrap:balance` を併用。
- **形**：カード角丸14〜20px、ボタンは丸型（999px）、影は2段階（`--shadow`／`--shadow-lg`）。
- **アイコン**：`index.html` 冒頭のSVGスプライト（矢印・下矢印・上矢印・チェック・？・グラフ・ペン・芽）を `<use href="#i-…">` で使う。線幅1.6〜2で統一。
- **ブレークポイント**：1100px（ナビ縮小・事例2列）／900px（1列化・ナビ非表示）／760px（スマホ）／360px（小型スマホ）。

## 7. 動作仕様

| 機能 | 仕様 |
|---|---|
| ページ内リンク | ナビ・CTAは各 `id` へスムーズスクロール。固定ヘッダーの高さぶん余白を取る（`scroll-padding-top`） |
| FAQ | HTML標準の `details` で開閉。1問目は初期で開く。JavaScriptなしでも動く |
| スマホの追従ボタン | 760px以下で、ヒーローを過ぎると画面下に「相談内容を登録する」を表示し、相談欄が見えている間は隠す。JavaScriptが無効なら出さない |
| 外部リンク | 事例4件と書籍は新しいタブで開く（`noopener noreferrer`） |
| 相談フォーム | `config.js` のURLが未設定の間は入力・送信できないダミー表示（入力欄・送信処理なし、ボタンは無効） |
| 動きの軽減 | OSで「視差効果を減らす」を設定している場合はスクロールやホバーのアニメーションを止める |

## 8. 相談フォーム（Airtable）の接続

2026-10-04に指定された専用フォームを `config.js` に設定しました。表示高さは提供された埋め込みコードに合わせて533pxです。

```js
window.AI_SUPPORT_CONFIG = Object.freeze({
  airtableEmbedUrl: "https://airtable.com/embed/app5A1Q6G2Lj1fcEU/pag990u2C5unJaER3/form",
  airtableFormUrl: "https://airtable.com/app5A1Q6G2Lj1fcEU/pag990u2C5unJaER3/form"
});
```

- 両方に `https://airtable.com/` のURL（埋め込み用は `/embed/` から始まる）が入ると、`script.js` がダミーを iframe と「フォームを別タブで開く」リンクに置き換える。片方でも空・不正ならダミーのまま。
- iframeを直接書く場合は、`index.html` の `AIRTABLE SLOT` コメント下の `#airtable-slot` の中身を差し替え、`config.js` は空のままにする（クラス `airtable-frame`、タイトル「農家向けAI伴走支援 相談登録フォーム」）。
- iframeの高さは `style.css` の `.airtable-frame` と `script.js` のheight属性で533pxに設定しています。
- 既存のインターン募集・無料モニター用フォームは流用しない。
